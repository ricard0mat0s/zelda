# 01: Project Scaffold, Vitest & Retro Title Screen

**What to build:** A working web app skeleton running Phaser 3 with TypeScript, Vite, and Vitest. When launched, the browser renders a pixel-perfect arcade title screen with a retro logo and "Press SPACE to Start" prompt that transitions to the game scene.

**Blocked by:** None (can start immediately)

**Status:** claimed

- [ ] `npm run dev` boots the local dev server without errors.
- [ ] `npx vitest run` runs successfully and reports 0 failing tests.
- [ ] `npx tsc --noEmit` passes with strict typechecking and 0 errors.
- [ ] Retro pixel title screen renders centered with integer pixel scaling.
- [ ] Pressing `SPACE` triggers transition from TitleScene to OverworldScene.
